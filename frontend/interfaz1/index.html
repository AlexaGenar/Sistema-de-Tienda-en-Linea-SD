Integración de Ethereum mediante RPC

Como parte de las operaciones especiales de la tienda, se integró Ethereum mediante RPC para obtener una estimación de la comisión de red cuando el usuario selecciona este método de pago.

Es importante señalar que la aplicación no realiza una transacción real con Ethereum. La funcionalidad utiliza los datos de una operación únicamente para estimar el gas necesario y, junto con el precio del gas obtenido de la red, calcular una comisión aproximada que se muestra al usuario.

Esta implementación permitió incorporar RPC con un propósito relacionado directamente con el proceso de compra, sin necesidad de realizar transferencias reales de criptomonedas.
